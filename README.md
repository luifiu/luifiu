## 📁 Projetos em destaque

### [📊 SalesOS — Dashboard de Vendas](https://github.com/luifiu/Dashboard-de-Vendas)
Dashboard interativo em página única com gráficos (linha, rosca, barras e radar), filtros por período e região, atualização automática a cada 60 s e exportação de relatório em PDF.
`HTML` `CSS` `JavaScript` `Chart.js` `jsPDF`

### [✅ TaskFlow — Gerenciador de Tarefas](https://github.com/luifiu/Sistema-de-Gerenciamento-de-Tarefas)
Aplicação web para criar, editar, filtrar e excluir tarefas (ativa, concluída, cancelada), com schema MySQL modelado (tabela, índices e stored procedure).
`HTML` `CSS` `JavaScript` `MySQL`

### [🐍 PyAnalyzer — Analisador de Código Python](https://github.com/luifiu/Analisador-de-C-digo-Python)
Analisa código Python via AST: complexidade ciclomática por função, detecção de blocos duplicados, nota de qualidade, histórico em SQLite e gráficos com matplotlib.
`Python` `ast` `SQLite` `matplotlib`

### [🎵 Árvore de Músicas](https://github.com/luifiu/arvore-de-musicas)
Árvore Binária de Busca em Java com inserção, busca, remoção, percursos (pré, em e pós-ordem) e menu interativo, carregando o catálogo de um CSV.
`Java` `Estruturas de Dados`
