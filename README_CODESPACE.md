# Codespace Dinossauro

Projeto de demonstração com um dinossauro animado (HTML/CSS/SVG) e fichas para destacar linguagens: HTML, CSS, JavaScript, Python, Java, SQL, MySQL.

Como abrir localmente

- Usando Python (porta 8000):

```bash
python3 -m http.server 8000
# então abra http://localhost:8000/index.html
```

- Em um Codespace / Live Server: abra `index.html` e use a opção de preview.

Estrutura

- `index.html` — marcação e interface
- `styles.css` — estilos e animações
- `script.js` — interatividade das fichas
